# Educational Desktop Player

Windows 10/11で、画面右下の小型ウィンドウから学ぶデスクトップアプリです。学習モードは短文・読解・単語帳の3つ。ゲームや学習成果の推定はありません。

呼称は「Educational Desktop Player」に統一します。同じ略称となる制作物が複数あるという本人の希望に従っています。提出された仕様の原文は `docs/REQUIREMENTS.md` に保持し、追加指示は `docs/HANDOFF.md` に記録しています。

## 起動

このアプリはワークスペースの `apps/EducationalDesktopPlayer/` にあります。共通プロフィール・入試調査は `../../shared/`、別のアプリは `../Exam-Dashboard-Planner/` に分離されています。通常は `../../起動/Educational Desktop Player.lnk` をダブルクリックします。

このワークスペースでは `Educational Desktop Playerを起動.cmd` をダブルクリックします。ビルド済みの `release/win-unpacked/Educational Desktop Player.exe` が起動し、画面右下に表示されます。タスクバーとは重ならない作業領域内に配置します。

cmdはASCII・CRLFで保存してください。LFのまま保存するとWindowsがコマンドを正しく解釈しない場合があります。日本語のファイル名やフォルダー名を変更する必要はありません。

- 短文・読解：最初は英文のみ。「解説」で和訳・解説を表示し、「次へ」「←」で前後へ進みます。移動後は和訳を隠します。読解は英文・和訳をそれぞれ一つの文章として表示します。
- 単語帳：中央のボタンで表面と裏面を切り替えます。前後移動は別のボタンです。
- 上部の空いている部分をドラッグして位置を変更し、ウィンドウの端からサイズを変更できます。集中モードでも上端の左側から移動できます。
- 右上の四隅のアイコンで詳細表示／集中モードを切り替えます。集中モードではタイトルバー・モード選択・モード表示・履歴・設定を隠し、ウィンドウの高さを縮めます。両表示のサイズをそれぞれ保存します。旧コンパクト設定は集中モードへ移行します。
- 詳細表示の「−」で一時非表示。再表示はタスクトレイのEアイコンをクリックします。集中モードでの非表示・一時停止・履歴・設定もトレイから操作できます。
- 終了はトレイの右クリックメニュー「終了」。再表示は他のアプリからフォーカスを奪わない方式です。
- 設定・履歴画面から戻るときは「学習に戻る」。一時停止中は時間を計測しません。

学習画面でこのアプリを操作中は、← 前へ、→ 次へ、↓ 解説、↑ 詳細表示／集中モード。ほかのアプリのキー入力は取得しません。設定の入力欄では通常の矢印キー操作を優先します。

「次へ」ではカードが少し右へ振れてから左へ移動し、次のカードが右から入ります。「前へ」は逆方向。切替中の連打による読み飛ばしを防ぎます。OSで動きを減らす設定を使っている場合は演出を省略します。

このワークスペースでは直接exeを起動しても `Educational Desktop Playerを起動.cmd` から起動しても、プロジェクトの `data/` を使います。Windows版フォルダーだけを別の場所へ移した場合はexeの隣の `data/` へ保存します。フォルダーを移動するときは保存データも含めて移してください。

## 技術と構成

Electron + React + TypeScript。esbuildで本体・preload・画面をビルドし、electron-builderでWindows x64フォルダー版を作ります。

| 場所 | 責務 |
| --- | --- |
| `src/main/` | ウィンドウ、トレイ、画面内復帰、限定したIPC |
| `src/renderer/` | 3モード、和訳・カード切替、設定・履歴の画面 |
| `src/core/` | 履歴保存・集計、コンテンツ検証、マーカー、配置計算 |
| `src/shared/types.ts` | モード・コンテンツ・IPCの型 |
| `content/` | 短文100教材・読解100教材と汎用カードのJSON |
| `content/authoring/` | 対訳・解説付き教材の編集原稿 |
| `docs/CURRICULUM.md` | 収録テーマ、教材ID、学習範囲、公式資料 |
| `docs/REQUIREMENTS.md` | 本人が提示した開発仕様 |
| `docs/CONTENT_SCHEMA.md` | コンテンツの追加・変更とデータ形式 |
| `docs/HANDOFF.md` | 次のAIへの開発引き継ぎ |
| `docs/IMPLEMENTATION.md` | 実装の判断と検証記録 |

画面側ではNode.jsを無効化し、context isolationとsandboxを使用します。IPCはこのローカル画面だけに限定。外部ページへの移動、別ウィンドウ、権限要求は許可しません。

## 保存と利用時間

`data/history.json` に起動・終了、セッション、モード別利用区間、表示と裏面表示の日時・コンテンツIDを保存します。`data/settings.json` にモード・表示番号・最前面・フォント・位置・サイズを保存します。本人情報やダッシュボードの学習履歴には書き込みません。

学習画面が表示され、一時停止されていない時間を集計します。非表示、設定・履歴画面、OSロック・スリープを除外。5秒ごとの保存により、異常終了では最大で直近5秒が記録されない可能性があります。復元時は最後に保存された時刻で前回を終了し、アプリ停止中の時間を加算しません。

履歴画面は今日・累計・モード別の時間と回数、最近の閲覧、セッションを表示。日時は日本時間です。「利用履歴を削除」は確認後に履歴を削除し、コンテンツと設定は保持します。閲覧を正解・理解・習得とは扱いません。

JSONは一時ファイルを書いてから置き換えます。読めないJSONは自動初期化せず起動を停止し、元ファイルを保持します。復元用のコピーはアプリを終了してから `data/` 全体を保存してください。

## 開発とビルド

Node.js 22.12以上が必要です。このPCでは24.14.1。依存バージョンは `package-lock.json` で固定します。

```powershell
npm ci
npm run typecheck
npm test
npm run build
npm start
npm run package
```

`npm run package` の出力は `release/win-unpacked/Educational Desktop Player.exe` と同じフォルダーの実行依存ファイルです。exe単体では配布せず、フォルダー全体を渡してください。コード署名とインストーラーは初期MVPには含みません。

更新には `scripts/package-windows.ps1` を使います。別フォルダーでビルドを完成させてから、このアプリだけを停止し、保存データをバックアップしてWindows版を差し替えます。ビルドに失敗した場合は差し替えません。バックアップは `.backups/` に保存し、Gitへ含めません。停止時点の保存済み記録を保持し、再起動では最後の保存時刻で前回セッションを区切ります。ビルド中にWindowsがexeを一時ロックした場合、`scripts/windows-resource-retry.cjs` はこのアプリのexeへの書込みだけを回数を制限して再試行します。

```powershell
npm run smoke
```

WindowsのElectronを専用テストデータで起動して操作・再起動を検証します。結果と画面画像は `artifacts/smoke/`、テスト履歴は `.test-data/`。本人の履歴は使いません。実際の検証結果は `docs/IMPLEMENTATION.md` に記録します。

実際のcmd経由でパッケージ版を検証する場合（Windows・PowerShell）：

```powershell
$env:DESKTOP_PLAYER_SMOKE_LAUNCHER = '1'
npm run smoke
Remove-Item Env:DESKTOP_PLAYER_SMOKE_LAUNCHER
```

検証時の `--wait` は終了を待つための引数です。通常のダブルクリックではバックグラウンドへ起動します。`DESKTOP_PLAYER_DATA_DIR` を指定すれば検証データを分離でき、未指定ではこのアプリの `data/` を使用します。

## 初期MVPの範囲

クリック透過、OSログイン時の自動起動、コンテンツのインポート画面、カードセット切替、画像添付編集、数式の組版は未実装です。カードの多行・数式種別を扱えるブロック構造はありますが、数式は文字として表示します。

2026年10月5日の本人指示で短文・読解を各100教材へ増量しました。短文はPart 5の語彙・文法・語法、読解はPart 6・7の接続関係・指示語・構造・文脈理解を扱います。読解は100文章（各2〜4文）です。和訳は濃い文字色・16px、英文との区切りの余白を従来の半分にしています。収録範囲と教材別テーマは `docs/CURRICULUM.md`、機械可読台帳は `content/curriculum.json` に保存。

教材を編集するときは `content/authoring/` の原稿を変更し、`npm run curriculum` でJSONと収録範囲資料を再生成して `npm test` で確認します。先頭の既存教材2件とIDを保持し、本人の保存データには書き込みません。原稿・台帳もWindows版のresources/contentに含まれます。
