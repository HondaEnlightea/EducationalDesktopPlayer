# Educational Desktop Player実装計画・判断記録

2026年10月4日。指定フォルダーはmain未コミット、既存のソースなし。originはHondaEnlightea/EducationalDesktopPlayer。Electron + React + TypeScriptを選択。

1. コンテンツのJSON定義・検証と、履歴・設定の原子的保存を実装。
2. ウィンドウ・トレイ・画面内配置・IPCを本体側に分離。
3. 短文・読解・汎用カードの3モードと、設定・履歴の画面を実装。
4. 集計・再起動・モード別時間・画面配置をテスト。Windowsで起動とビルドを確認。

利用時間は学習画面が表示され、セッションが一時停止されていない区間。設定・履歴・非表示・OSサスペンド・ロック中は除外する。起動と終了の日時は別に保存。前回が異常終了した場合は最終保存時刻で区切り、停止していた時間を利用時間へ加算しない。

自動起動登録、クリック透過、インポート、数式組版、画像編集は初期MVPの必須に含めない。少量のオリジナル動作確認用データのみ用意する。

## 実装済みの内容

枠なし・角丸・画面右下配置のWindows常駐ウィンドウを実装。作業領域を使ってタスクバーとの重なりを避け、移動・サイズ変更・モニター変更時の画面内復帰、最前面切替、通常／コンパクト、一時非表示、トレイ再表示・終了に対応する。起動・再表示は `showInactive` を使用する。

短文は1〜2文、読解は2〜4文のJSON。初期は英文だけを表示し、操作で文ごとの和訳・指定したマーカー・解説を表示する。単語帳はID・カテゴリ・表裏ブロック・任意の注記とタグを持つ。前後移動と表示切替を別のボタンにする。初期データは短文2件・読解2件・英語カード3件。

履歴はセッション、起動・終了日時、モード別利用区間、表示・和訳／裏面表示イベントをローカルJSONへ保存。設定・位置・サイズ・各モードの表示番号も保存。履歴画面で本日・累計・モード別の時間と回数、最近のイベント、セッションを確認できる。削除は確認ダイアログの後に実行する。
