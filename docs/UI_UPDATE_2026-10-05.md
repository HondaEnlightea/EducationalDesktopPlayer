# 2026年10月5日：本人が指定したUI変更

目標はスマートでスタイリッシュな常駐学習アプリ。別作業と並行するため、冗長な表示を削る。

1. コンパクト表示を廃止し、集中モードを用意する。タイトルバー、モード選択、モード表示、履歴・設定を隠す。右上に詳細表示／集中モードの切替ボタンを残す。
2. 読解の余白を減らし、英文と和訳をそれぞれ単一の塊として表示する。
3. 次へでは、現在のカードを少し右へ振ってから左へ送り、次のカードを右から表示する。
4. 次へと解説を同じ大きさにする。ボタンの文言は「解説」に短縮する。
5. 矢印キー：左右で前後移動、下で解説、上で詳細／集中モード切替。

## 実装上の判断

- 集中モードの初回切替では高さを148px減らす（最小240px）。右下の位置を基準にし、詳細へ戻すと元の寸法を復元。手動変更した集中・詳細の寸法はそれぞれ保存する。
- 集中モードは学習内容の追加モードではなく、3つの学習モード共通の表示設定。履歴と設定にはトレイからアクセスする。
- 集中モードの上端左側に見えないドラッグ領域を残す。右上の切替ボタンとは重ねない。本文は選択とスクロールができる。
- 読解の元データ・マーカーは文単位を維持する。画面では文を順に連結し、英文、和訳、補足の順に表示する。
- カード演出は約380ms。前へは逆方向にし、動きを減らすOS設定では省略する。演出中の連打・キーリピートによる多重移動を防ぐ。
- キーはこのアプリの学習画面だけで処理する。ほかのアプリから入力を取得せず、修飾キー付き操作と設定の入力を優先する。
- 旧コンパクトの設定は集中モードへ移行し、表示番号・フォント・位置・通常サイズを保つ。旧設定ファイルを手作業で初期化しない。

元の開発指示書は変更せず保存する。新しい本人指示が表示仕様に優先する。機能検証結果と配布版更新は `IMPLEMENTATION.md` に記録する。

## 続く本人指示：和訳の視認性と教材の増量

1. 和訳は薄い字にせず、フォントサイズを一段階上げる。本文と同じ濃い色 `#263c36`、14→16pxに変更。
2. 英文と和訳の間の区切りが取りすぎていた余白を半分にする。読解の区切り上側12→6px、下側10→5px。
3. 短文・読解をそれぞれ100文程度作り、TOEIC高得点に向けて幅広い学習を収録する。従来の役割に沿って短文100教材・読解100教材（各2〜4文）として実装し、対訳・語句／文法解説・論理関係／文脈の確認ポイントを付ける。初期少量データの制約はこの本人指示で更新する。

収録範囲と教材別IDは `CURRICULUM.md` と `content/curriculum.json`。全英語・全出題を100件で漏れなくカバーできるとは扱わず、長文・実際の問題形式・Listeningで補う範囲も明文化する。新しい学習モードや学習成果の推定は加えない。
